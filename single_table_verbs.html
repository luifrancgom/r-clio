10  Verbos de una sola tabla

Este capítulo se basa en (Wickham, 2023, Capítulo 3) así como en la documentación oficial de dplyr donde tiene como propósito introducir una gramática de manipulación de datos a través de un conjunto consistente de verbos para resolver las tareas más comunes en el manejo de datos cuando se tiene una sola tabla utilizando el paquete dplyr e información de los resultados del examen Saber Pro del grupo de competencias genéricas correspondientes al periodo 2021-2024 para Colombia.

Exploraremos los siguientes aspectos:

  1. ¿En qué consiste la gramática de manipulación de datos utilizada en dplyr?
  2. ¿Qué y cuáles son los verbos de una sola tabla para filas?
  3. ¿Qué y cuáles son los verbos de una sola tabla para columnas?
  4. ¿Qué y cuáles son los verbos de una sola tabla para colapsar, agrupar o desagrupar filas?
  5. ¿Qué es y para qué sirve el operador pipe (|>)?

10.1 Gramática de manipulación de datos en dplyr

El paquete dplyr, incluido en el tidyverse, permite manipular datos a partir de un conjunto de datos en 2 niveles:

  1. Dentro de una sola tabla de datos
  2. Entre diferentes tablas de datos

El primer nivel se abarcará en el Capítulo 10 y el segundo nivel se desarrollará en el Capítulo 11. Al igual que en el caso de ggplot2 (ver Sección 6.1) el paquete dplyr funciona mejor si el conjunto de datos es ordenado (tidy data en inglés, (Wickham, 2014)) donde este concepto se tratará en más detalle en el Capítulo 16.

A medida que explores diferentes formas de manipular un conjunto de datos entenderás en más detalle la gramática de manipulación de datos propuesta en el paquete dplyr. Por ahora se describirán en la Sección 10.1.1 de manera general y gráfica los verbos más comunes que se utilizan para manipular datos en una sola tabla y que se utilizan en dplyr.

En el paquete dplyr, para mantener la consistencia de las funciones que lo componen, siempre se cumple que cada uno de los verbos obedece a los siguientes aspectos (Wickham, 2023, Capítulo 3):

  1. El primer argumento es una tibble (o en su defecto un objeto de R similar).
  2. Los argumentos subsiguientes especifican las columnas, filas o expresiones que operarán sobre las filas o columnas.
  3. El resultado1 de una función en dplyr es siempre una nueva tibble (o en su defecto un objeto de R similar).

10.1.1 Verbos

Los verbos para manipular datos en una sola tabla se encuentran organizados en 3 categorías teniendo en cuenta el elemento que se desea manipular:

  1. Verbos para filas
  2. Verbos para columnas
  3. Verbos para colapsar, agrupar o desagrupar filas

Debido a que la manipulación de datos requiere realizar un conjunto de operaciones de manera secuencial, se hace necesario contar con un operador que “encadene” de forma armónica cada una de las transformaciones deseadas. Para este propósito se utiliza el operador pipe (|>), el cual se abordará con mayor detalle en la Sección 10.1.1.3.

10.1.1.1 Verbos para filas

Esta categoría incluye las funciones filter(), slice() y arrange(). La primera función, correspondiente a filter(), se utiliza para seleccionar filas con base en una expresión que retorne un vector lógico donde usualmente se hace uso de operadores relacionales (ver Sección 5.5). La selección de las columnas se realiza con base en el nombre de las variables o a su tipo donde se pueden utilizar operadores o funciones auxiliares. En la Figura 10.4 se ilustra gráficamente la manipulación que se puede realizar con la función select().

La tercera función, correspondiente a mutate(), se utiliza para crear nuevas columnas usualmente a partir de variables existentes dentro de una tibble. También se puede utilizar para modificar columnas si el nombre es el mismo a una columna existente. La función mutate() por defecto ubica las nuevas columnas al final de la tibble y mantiene todas las variables presentes en la tibble original. Sin embargo estos aspectos se pueden modificar con los parámetros .keep, .before y .after (ver ?mutate). En la Figura 10.6 se ilustra gráficamente la manipulación que se puede realizar con la función mutate().

Para utilizar un ejemplo concreto puedes utilizar el conjunto de datos 2021-2024_saber-pro-genericas_faedis.rds para generar una nueva columna denominada punt_global_norm donde corresponde a la variable punt_global normalizada en el intervalo \([0, 1]\)3 y conservando sólo las columnas utilizadas para generar ésta nueva variable a través del parámetro .keep con el argumento "used", como .keep = "used":

mutate(
  saber_pro_genericas_faedis_2021_2024,
  punt_global_norm = (punt_global - min(punt_global)) /
    (max(punt_global) - min(punt_global)),
  .keep = "used"
)

10.1.1.3 Operador pipe (|>)

El operador pipe (|>) permite realizar este proceso donde fue introducido en la versión 4.1.0 de R y motivado por un operador similar del paquete magrittr perteneciente al tidyverse (ver ?`|>`). Debido a que en el paquete dplyr se utilizan funciones para manipular datos en la Tabla 10.1 se ilustra el uso y la interpretación del operador |>.

En Positron, puedes insertar el operador |> utilizando la combinación de teclas de tal manera que no tengas que digitarlo de manera manual.

El Listado 10.1 ilustra las ventajas de hacer uso del operador |> para que el código sea más legible donde permite:

  2. Evita el uso de funciones anidadas
  3. Minimiza la necesidad de crear variables intermedias o definiciones de funciones
  4. Facilita agregar o eliminar pasos en cualquier parte de la secuencia en caso de que se requiera

También es posible crear variables intermedias donde este enfoque se ilustra en el Listado 10.3 utilizando el mismo código, tal como se señala a continuación:

En el Listado 10.3 se crean variables intermedias adicionales para un análisis sencillo. Sin embargo, esta práctica puede saturar el entorno de trabajo, aumentar el riesgo de cometer errores por confusión de nombres y dificulta el mantenimiento del código si se desea agregar un nuevo paso en la secuencia4.

Esto no significa que se deba optar por el extremo opuesto y utilizar el operador |> de manera indiscriminada para generar secuencias interminables de pasos. En la práctica en el análisis de datos, tarde o temprano será necesario e incluso recomendable crear variables intermedias. La clave no es eliminar por completo la creación de variables, sino aprender a gestionar un conjunto mínimo y adecuado de variables con un propósito claro, en lugar de lidiar con una enorme cantidad de objetos.

En la Tabla 10.1 se señala en la última fila el uso del guion bajo (_). Este elemento funciona como un marcador de posición (placeholder en inglés) que sirve para controlar de manera explícita en qué lugar se insertará el objeto debido a que, por defecto, este se introduce como el primer argumento de una función al utilizar el operador |>. 10.1.1.4 Verbos para colapsar, agrupar y desagrupar filas

Esta categoría incluye las funciones group_by(), summarise() y ungroup(). La primera función, correspondiente a group_by(), se utiliza para convertir una tibble en una tibble agrupada de tal manera que los verbos posteriores que se utilicen se apliquen por grupo. En la Figura 10.8 se ilustra gráficamente la manipulación que se puede realizar con la función group_by().

Para ilustrar el comportamiento de esta función con un ejemplo concreto puedes utilizar el conjunto de datos 2021-2024_saber-pro-genericas_faedis.rds para agruparlos por año y el género a través de las variables ano y estu_genero:

saber_pro_genericas_faedis_2021_2024 |>
  group_by(
    ano,
    estu_genero
  )

Por defecto cuando existen variables agrupadas la función summarise() desagrupa por la última variable el resultado final, en este caso por estu_genero. Debido a lo anterior el paquete dplyr genera un mensaje indicando este comportamiento así como diferentes alternativas para no utilizar la función group_by() mediante el uso del parámetro .by y el argumento c(ano, estu_genero), como .by = c(ano, estu_genero). Aunque existe la anterior alternativa (ver Importante 10.1) a lo largo del libro se utilizará de manera explícita la función group_by() cuando se busque hacer uso de la función summarise() para calcular estadísticas descriptivas por grupos.

Importante 10.1

En el paquete dplyr existen \(2\) formas de agrupar:

  1. Utilizando group_by() donde la agrupación persiste al aplicar diferentes verbos.
  2. Utilizando los parámetros .by o by dentro de un determinado verbo donde la agrupación sólo afecta el verbo donde se utilice el parámetro.

El lector interesado puede consultar la documentación oficial de dplyr para conocer más detalles de este aspecto en caso de que sea de su interés. Sin embargo, a lo largo del libro utilizaremos la función group_by() de manera explícita y no los parámetros .by o by dentro de los verbos.

Una vez estés familiarizado con el paquete dplyr podrás examinar el comportamiento de utilizar una u otra opción. Por ahora el enfoque es conocer los diferentes verbos disponibles en el contexto de la gramática de manipulación de datos.

10.2.5 Modificar (mutate())

El cuarto paso para reconstruir el conjunto de datos 2021-2024_saber-pro-genericas_faedis.rds comprende modificar algunas de las columnas relacionadas con las \(20\) variables indicadas en la Sección 6.2.1 utilizando la función mutate(). Aunque la función mutate() también se puede utilizar para generar nuevas variables el propósito en este caso es asociar el tipo adecuado de ciertas variables dentro de R. Algunas variables no son continuas sino discretas y en otros casos existen variables categóricas que son nominales u ordinales pero que están codificadas como caracteres.

R implementa diferentes tipos de datos que se pueden utilizar para acomodar los aspectos mencionados anteriormente. Aunque no abarcaremos en la Sección 10.2.5 todos los tipos de datos que R implementa, en la Tabla 10.2 se indican algunos de los tipos más comunes y que se utilizarán más adelante. El lector interesado en conocer en más detalle los tipos de datos más comunes y su funcionamiento puede consultar (Wickham, 2019, Capítulo 3).

En el Listado 10.9 se utilizan las funciones as.integer() y factor() junto con la función mutate() para transformar variables que son inicialmente continuas y caracteres a enteros y factores. La implementación en R de variables nominales y ordinales o en general de variables categóricas se realiza a través del concepto de factor (ver ?factor). Para definir las categorías que abarca un factor se utiliza el parámetro level junto con un vector como argumento donde se puede especificar si existe o no un ordenamiento a través del parámetro ordered donde el argumento puede tomar el valor de FALSE (si es una variable nominal) o TRUE (si es una variable ordinal), tal como se señala a continuación:
