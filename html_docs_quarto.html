22  Documentos HTML con Quarto

Este capítulo se basa en (Posit, 2026) y (Wickham, 2023, Capítulo 28) así como en la documentación oficial de quarto donde tiene como propósito introducir la forma de generar reportes a través del uso de Quarto en formato HTML mediante la recreación del reporte reporte_umng-ingles.html a partir de los resultados del examen Saber Pro del grupo de competencias genéricas correspondientes a programas de pregrado de la Universidad Militar Nueva Granada (UMNG).

Exploraremos los siguientes aspectos:

  1. ¿Cómo escribir un reporte en Markdown?
  2. ¿Cómo controlar los aspectos globales del reporte utilizando YAML?
  3. ¿Cómo incorporar celdas de código en un reporte?
  4. ¿Cómo incluir bloques de llamada, referencias cruzadas y otros elementos adicionales en un reporte?

22.1 Escritura con Markdown

Al estructurar un reporte técnico o científico en Quarto, una práctica recomendada consiste en diseñar primero el esquema general y la narrativa mediante texto en formato Markdown, postergando temporalmente la inclusión de celdas de código, fórmulas matemáticas complejas y referencias cruzadas automatizadas (Wickham, 2023, Capítulo 28).

Para iniciar el archivo reporte_umng-ingles.qmd dentro de la carpeta reports, establece un encabezado YAML mínimo y define los encabezados principales del documento de acuerdo con la siguiente estructura inicial:

---
title: "Resultados Saber Pro: Competencia Genérica en Inglés (UMNG 2021-2024)"
date: 2026-11-25
format:
  html:
    code-fold: true
    embed-resources: true
lang: es
engine: knitr
---

# Introducción



# Marco de Evaluación de la Competencia



# Beneficios del Aprendizaje de Lenguas Extranjeras



# Resultados Saber Pro UMNG (2021-2024)



## Estimación de Estadísticos Descriptivos Agregados



# Oportunidades de Mejora para Pregrado

En este punto inicial, el documento cuenta con un encabezado YAML básico que define el título, la fecha, el formato de salida HTML con plegado de código (code-fold: true), la integración de recursos en un único archivo (embed-resources: true), el idioma español (lang: es) y el motor de evaluación (engine: knitr).

A continuación, se procede a redactar únicamente la narrativa en Markdown para cada una de las secciones, sin incorporar aún bloques de código ejecutable, ecuaciones matemáticas ni referencias cruzadas con la sintaxis de Quarto (@fig-..., @tbl-... o @eq-...). En su lugar, cualquier alusión a figuras o tablas se escribe en texto plano simple (por ejemplo, redactando explícitamente “Figura 1”, “Figura 2” o “Tabla 1”), como se suele hacer en una primera versión narrativa antes de automatizar los enlaces. Asimismo, para visualizar los bloques de texto extenso sin necesidad de desplazarse horizontalmente, se puede aplicar la clase CSS .code-overflow-wrap al bloque de código estático (por ejemplo, mediante ```{.markdown .code-overflow-wrap}).

22.2 Control del documento con YAML

Una vez estructurado el cuerpo narrativo del informe, el encabezado YAML permite configurar de forma global el comportamiento del documento, los metadatos bibliográficos, la navegación y las opciones de renderizado (Posit, 2026).

A continuación se presenta el encabezado YAML completo utilizado en reporte_umng-ingles.qmd:

---
title: "Resultados Saber Pro: Competencia Genérica en Inglés (UMNG 2021-2024)"
date: 2026-11-25
toc: true
number-sections: true
format:
  html:
    code-fold: true
    embed-resources: true
lang: es
engine: knitr
bibliography: ../references/reporte-umng.bib
csl: ../references/apa.csl
---

Cada una de estas opciones cumple una función específica dentro de la publicación del reporte:

  1. title y date: Especifican los metadatos principales del documento. La fecha se define preferentemente en formato ISO estándar (AAAA-MM-DD, por ejemplo 2026-11-25) o mediante la instrucción dinámica last-modified, lo cual garantiza que la fecha refleje la última compilación del archivo.
  2. toc: true (Table of Contents): Activa la tabla de contenido interactiva. En documentos HTML de Quarto, esta tabla se ubica de forma flotante en el margen lateral derecho, permitiendo al lector desplazarse de manera ágil entre los encabezados y subencabezados del informe.
  3. number-sections: true: Numera automáticamente las secciones y subsecciones del reporte de forma jerárquica (1, 1.1, 2, 3, etc.), garantizando coherencia estructural a lo largo de todo el documento.
  4. format: html: Define las opciones específicas para el formato web:
    • code-fold: true: Pliega automáticamente todos los bloques de código R al compilar el documento. En la vista HTML, cada bloque se muestra contraído bajo un botón interactivo rotulado como Código, permitiendo al usuario inspeccionar las instrucciones solo si así lo desea, sin interrumpir la lectura del texto y los gráficos.
    • embed-resources: true: Consolida todos los archivos CSS, bibliotecas de JavaScript e imágenes dentro del propio archivo .html. De esta forma se genera un reporte web completamente autónomo e independiente, ideal para compartir por correo electrónico o subir a plataformas de aprendizaje sin preocuparse por rutas rotas o carpetas complementarias faltantes.
  5. lang: es: Establece el idioma del documento en español. Quarto utiliza esta directiva para traducir automáticamente las etiquetas predeterminadas del sistema, tales como “Tabla de contenidos”, “Figura”, “Tabla” y “Código”.
  6. engine: knitr: Especifica explícitamente a knitr como el motor de evaluación computacional para las celdas de código en R.
  7. bibliography: ../references/reporte-umng.bib: Establece la ruta relativa hacia el archivo en formato BibTeX que almacena las entradas bibliográficas del informe.
  8. csl: ../references/apa.csl: Vincula el archivo de estilo de citación (Citation Style Language), en este caso correspondiente a la 7.ª edición de las normas APA, el cual gobierna la presentación formal de las citas dentro del texto y el listado de referencias final.

22.3 Incorporación de celdas de código

Las celdas de código permiten intercalar instrucciones reproducibles de R directamente con la narrativa en Markdown (Wickham, 2023, Capítulo 28). En Quarto, la configuración de cada celda se realiza mediante la sintaxis hashpipe (#|), ubicando las opciones en pares clave: valor al inicio del bloque de código.

A continuación, se describen las 5 celdas de código necesarias para generar el análisis empírico de reporte_umng-ingles.qmd, haciendo especial énfasis en la creación de tablas profesionales con el paquete knitr y la función kable().

22.3.4 Transformación y resumen estadístico

En la subsección ## Estimación de Estadísticos Descriptivos Agregados, se agrega la celda que ejecuta la agregación temporal:

```{r}
#| label: agrupar-colapsar
saber_pro_ingles_agrupado_2021_2024_umng <- saber_pro_ingles_2021_2024_umng |>
  group_by(ano) |>

    mean_floor = as.integer(mean(mod_ingles_punt)),

```

Esta celda agrupa las observaciones por año mediante group_by(ano) y calcula la media y desviación estándar muestrales, aplicando la coerción as.integer() para truncar los valores al entero inmediatamente inferior según la función piso.

22.3.5 Construcción de tablas con knitr y la función kable

A diferencia de un script interactivo en el que se imprime un data frame o tibble en texto plano en la consola, en un documento científico de Quarto se debe convertir el objeto de R en una tabla tipográfica formateada (Wickham, 2023, Capítulo 28). La función kable() del paquete knitr proporciona el mecanismo estándar para lograr este resultado.

A continuación de la celda de agregación, se inserta la celda que genera la tabla resumen:

```{r}
#| label: tbl-resumen
#| tbl-cap: "Media y desviación estándar truncadas (piso) del puntaje del módulo de inglés por año en la UMNG según las @eq-media-piso y @eq-desviacion-piso."
saber_pro_ingles_agrupado_2021_2024_umng |>
  kable(
    format = "pipe",
    col.names = c(
      "**Año ($j$)**",
      "**Media ($\\bar{x}_{j, \\text{piso}}$)**",
      "**Desviación estándar ($s_{j, \\text{piso}}$)**"
    ),
    align = c("c", "c", "c")
  )
```

Analicemos los componentes esenciales de esta celda:

  1. #| label: tbl-resumen: Al comenzar con el prefijo reservado tbl-, Quarto interpreta la salida como una tabla numerada que podrá ser referenciada en cualquier punto del documento mediante @tbl-resumen.
  2. #| tbl-cap: "...": Especifica el título descriptivo de la tabla que se mostrará en el encabezado de la misma.
  3. format = "pipe": Instruye a kable() para construir la tabla utilizando la sintaxis de tablas de tubería de Markdown (| col1 | col2 |), facilitando que Pandoc la procese y aplique el estilo visual óptimo en HTML.
  4. col.names = c(...): Permite renombrar los encabezados de las columnas utilizando formato enriquecido de Markdown (como negrita **...**) e incluso expresiones matemáticas en LaTeX (como $j$ o $\bar{x}_{j, \text{piso}}$). Ten en cuenta que en cadenas de caracteres de R se debe utilizar la doble barra invertida \\ para escapar los comandos de LaTeX (por ejemplo, \\text{piso} y \\bar{x}).
  5. align = c("c", "c", "c"): Controla la alineación horizontal del contenido de cada columna. En este caso, el vector indica que las 3 columnas deben estar centradas ("c" para centro, "l" para izquierda y "r" para derecha).

22.4 Bloques de llamada, referencias cruzadas y más

Con la narrativa y las celdas de código definidas, se procede a incorporar los elementos avanzados que elevan la calidad formal del reporte: bloques de llamada (callouts), referencias cruzadas dinámicas, ecuaciones matemáticas y gestión automatizada de citas y bibliografía con Zotero y estilos CSL.

22.4.1 Bloques de llamada

Los bloques de llamada (callouts) permiten destacar información complementaria, advertencias, notas metodológicas o consejos sin romper el flujo de lectura (team, 2026). Quarto admite 5 tipos estándar de bloques de llamada: .callout-note, .callout-tip, .callout-warning, .callout-caution y .callout-important.

En reporte_umng-ingles.qmd, justo antes de la carga de paquetes, se inserta un bloque de llamada de advertencia para aclarar el carácter del análisis:

::: {.callout-warning}
### Aviso preliminar
El presente reporte constituye un ejercicio analítico preliminar y no representa un documento oficial ni una versión definitiva.
:::

Al renderizar en HTML, este bloque se presenta con un borde visual distintivo, un ícono de advertencia y un encabezado destacado, alertando de inmediato al lector.

22.4.2 Referencias cruzadas automáticas

En lugar de escribir manualmente “Figura 1” o “Tabla 1” en texto estático —lo cual resulta propenso a desincronizaciones si se modifica el orden de los elementos—, Quarto proporciona un sistema unificado de referencias cruzadas basado en prefijos reservados (Wickham, 2023, Capítulo 28).

Para habilitar una referencia cruzada:

  1. Se asigna una etiqueta identificadora con el prefijo correspondiente al elemento:
    • fig- para figuras e imágenes.
    • tbl- para tablas.
    • eq- para ecuaciones matemáticas.
    • sec- para títulos y secciones.
  2. En el texto narrativo, se hace referencia al identificador anteponiendo el símbolo @ (por ejemplo, @fig-beneficios o @tbl-resumen). Quarto sustituye dinámicamente este identificador por el texto localizado correspondiente (por ejemplo, “Figura 1” o “Tabla 1”) y genera un enlace hipertextual navegable.

En reporte_umng-ingles.qmd, las referencias cruzadas se configuran de la siguiente manera:

22.4.2.1 Imágenes estáticas

Para la imagen de beneficios del aprendizaje de lenguas, se añade el identificador {#fig-beneficios} en los atributos de la figura:

![Beneficios formativos, económicos y cognitivos del aprendizaje de lenguas extranjeras adaptado de @oecd_pisa_2021.](../images/benefits-foreign-language-learning.png){#fig-beneficios fig-align="center" width="60%"}

Y en el párrafo anterior se referencia dinámicamente:

... los beneficios derivados de esta competencia se agrupan en 3 dimensiones (ver @fig-beneficios):

De igual forma, para la ruta de oportunidades de mejora, se define {#fig-plan}:

![Ruta secuencial de oportunidades de mejora en 3 fases para estudiantes de pregrado de la UMNG.](../images/plan-improvement-opportunities.png){#fig-plan fig-align="center" width="95%"}

Y se referencia en el texto con (ver @fig-plan).

22.4.2.2 Gráficos y tablas generados con código

En los bloques de código R, el identificador se declara en la opción #| label::

  • En el histograma, #| label: fig-distribucion permite referenciar el gráfico en el texto con:

    En la @fig-distribucion se presenta la distribución anual de los puntajes individuales...

  • En la tabla de resumen, #| label: tbl-resumen permite referenciar la tabla con:

    ... se obtienen las estimaciones anuales reportadas en la @tbl-resumen.

22.4.2.3 Ecuaciones matemáticas

Quarto permite formular ecuaciones en LaTeX y etiquetarlas con el prefijo {#eq-...}. En la subsección ## Estimación de Estadísticos Descriptivos Agregados, se incorporan las fórmulas de la media truncada y de la desviación estándar truncada:

$$
\bar{x}_{j, \text{piso}} = \left\lfloor \frac{1}{n_j} \sum_{i=1}^{n_j} x_{ij} \right\rfloor
$$ {#eq-media-piso}

$$
s_{j, \text{piso}} = \left\lfloor \sqrt{\frac{1}{n_j - 1} \sum_{i=1}^{n_j} (x_{ij} - \bar{x}_j)^2} \right\rfloor
$$ {#eq-desviacion-piso}

En la narrativa, estas expresiones se referencian fluidamente utilizando @eq-media-piso y @eq-desviacion-piso:

... se estiman la media muestral truncada mediante la @eq-media-piso y la desviación estándar truncada mediante la @eq-desviacion-piso...

22.4.3 Gestor bibliográfico Zotero y estilos CSL

El manejo riguroso de fuentes en Quarto se apoya en dos herramientas fundamentales: los archivos BibTeX (.bib) y los archivos de estilo de citación (Citation Style Language, .csl).

22.4.3.1 Creación del archivo .bib con Zotero

Zotero es un gestor de referencias bibliográficas de código abierto y gratuito. Permite capturar referencias desde navegadores web, bases de datos académicas o catálogos bibliográficos, organizarlas en colecciones y exportarlas en formato BibTeX.

Para generar un archivo .bib utilizable en Quarto:

  1. Selecciona en Zotero la colección de documentos correspondiente a tu investigación.
  2. Haz clic derecho sobre la colección y elige la opción Exportar colección… (o Export Collection…).
  3. Selecciona el formato BibTeX (o Better BibTeX si tienes instalada dicha extensión).
  4. Guarda el archivo con el nombre reporte-umng.bib dentro de la carpeta references/ de tu proyecto.

Cada registro exportado cuenta con una clave de citación única (por ejemplo, icfes_guiorientacion_2024 u oecd_pisa_2021), como se aprecia en el contenido de references/reporte-umng.bib:

@book{oecd_pisa_2021,
    series = {{PISA}},
    title = {{PISA} 2025 {Foreign} {Language} {Assessment}},
    url = {https://www.oecd.org/content/dam/oecd/en/topics/policy-sub-issues/foreign-language-learning/PISA-2025-FLA-Framework.pdf},
    language = {en},
    urldate = {2026-11-24},
    publisher = {OECD Publishing},
    author = {{OECD}},
    year = {2021},
}

@misc{icfes_guiorientacion_2024,
    title = {Guía de orientación del examen {Saber} {Pro} {Aplicación} 2024-2 {Módulo} de competencias genéricas},
    url = {https://www.icfes.gov.co/wp-content/uploads/2024/11/10-Mayo_GDO-Mo%CC%81dulos-Gene%CC%81ricos-Saber-Pro-2024-2-1.pdf},
    language = {es},
    urldate = {2026-11-24},
    author = {ICFES},
    year = {2024},
}

22.4.3.2 Aplicación de estilos con Citation Style Language (CSL)

El estándar Citation Style Language (CSL) permite dar formato a las citas y a la bibliografía según las pautas de miles de revistas y manuales de estilo internacionales.

En el repositorio oficial Zotero Style Repository, puedes buscar y descargar libremente más de 10.000 estilos bibliográficos (como American Psychological Association 7th edition, IEEE, Vancouver, Chicago, entre otros). Para aplicar el estilo APA 7.ª edición en tu reporte:

  1. Ingresa a https://www.zotero.org/styles.
  2. Busca “American Psychological Association 7th edition”.
  3. Descarga el archivo apa.csl y ubícalo en la carpeta references/.
  4. Enlaza este archivo en el encabezado YAML mediante la propiedad csl: ../references/apa.csl.

22.4.3.3 Sintaxis para insertar citas en el reporte

En Quarto, las citas se incorporan en el texto utilizando la clave de citación del archivo .bib:

  • Cita parentética: [@clave] produce (Autor, Año). Por ejemplo, [@icfes_guiorientacion_2024, p. 57] genera (ICFES, 2024, p. 57).
  • Cita narrativa o en el texto: @clave produce Autor (Año). Por ejemplo, @oecd_pisa_2021 genera OECD (2021).
  • Múltiples citas: separadas por punto y coma [@clave1; @clave2].

Al final del documento, Quarto genera automáticamente el listado de referencias bibliográficas formateado bajo el encabezado final # Referencias:

# Referencias

22.4.4 Estilo CSS personalizado para justificar texto

De forma predeterminada, los navegadores alinean el texto hacia la izquierda. Si deseas justificar los párrafos para dar una apariencia editorial más sobria al reporte HTML, puedes insertar un bloque de código HTML puro con reglas CSS directamente después de la celda de carga de paquetes:

```{=html}
<style>
  p { 
    text-align: justify;
  }
</style>
```
