13  Texto plano

Este capítulo se basa en (Wickham, 2023, Capítulo 7) así como en la documentación oficial de readr donde tiene como propósito introducir la importación y exportación de datos de archivos de texto plano rectangulares.

Exploraremos los siguientes aspectos:

  1. ¿Qué es un archivo .csv, por qué se usa I() para leer cadenas en memoria y cómo utilizar argumentos clave como skip, comment, col_names y na con read_csv()?
  2. ¿Cómo importar otros formatos de archivos de texto plano rectangulares (.tsv, archivos delimitados por punto y coma, delimitadores personalizados y archivos de ancho fijo)?
  3. ¿Cómo controlar los tipos de datos en las columnas mediante col_types y diagnosticar problemas de importación con problems()?
  4. ¿Cómo exportar tablas de datos a archivos de texto plano desde R?

Para desarrollar el contenido de este capítulo, procede a crear una nueva carpeta llamada 013_importar-datos-texto-plano-en-r y dentro de ella genera el archivo 001_importar-datos-formato-texto-plano.R, siguiendo las pautas de la Sección 4.4.

13.1 Archivos de valores separados por comas (.csv)

Un archivo con formato .csv (en inglés comma-separated values) es un archivo de texto plano estructurado de forma rectangular donde cada línea del archivo representa una fila o registro y las columnas o campos se encuentran separados por comas (,). Generalmente, la primera línea del archivo contiene los encabezados o nombres de las variables.

Cuando uno de los campos de texto contiene una coma dentro de su propio contenido, dicho campo se delimita entre comillas dobles (") para evitar que la coma interna sea interpretada erróneamente como un separador de columnas.

Para importar archivos .csv a R se utiliza la función read_csv() del paquete readr. El primer parámetro de esta función es file, el cual usualmente recibe una ruta hacia un archivo almacenado en disco (por ejemplo, "data/programas.csv"). No obstante, para realizar pruebas o construir ejemplos ilustrativos, también es posible suministrar datos directamente desde una cadena de texto en memoria.

Para que readr distinga explícitamente que la cadena contiene datos literales en lugar de una ruta a un archivo en disco, se utiliza la función I() (As-Is) de R base al asociar el argumento con file, tal como se ilustra a continuación:

Rows: 7 Columns: 2
── Column specification ────────────────────────────────────
Delimiter: ","
chr (1): nombre_programa
dbl (1): codigo_snies

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.

En el Listado 13.1, la cadena pregrado_faedis_csv define dos columnas (codigo_snies y nombre_programa). Observa los siguientes detalles:

  1. Uso de I(): envolver la variable como I(pregrado_faedis_csv) le indica a read_csv() que interprete el contenido del objeto como los datos mismos (literal data) y no como el nombre de un archivo que deba buscar en disco.
  2. Campos con comas internas: el programa "Administración de Riesgos, Seguridad y Salud en el Trabajo" se encuentra entre comillas escapadas (\") para que la coma no divida el texto en columnas adicionales.
  3. Especificación de columnas: al ejecutar la función, readr imprime un mensaje informativo (Column specification) indicando que codigo_snies fue inferido como número real (<dbl>) y nombre_programa como carácter (<chr>).

13.1.1 Parámetros comunes al importar datos

Los archivos de texto plano en escenarios reales suelen contener metadatos, comentarios o estructuras no convencionales. La función read_csv() proporciona diversos parámetros para controlar el proceso de importación:

  1. skip: permite omitir un número determinado de líneas al inicio del archivo antes de comenzar la lectura de los datos. Resulta útil cuando el archivo incluye metadatos o encabezados explicativos:
Rows: 2 Columns: 2
── Column specification ────────────────────────────────────
Delimiter: ","
chr (1): nombre_programa
dbl (1): codigo_snies

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.
# A tibble: 2 × 2
  codigo_snies nombre_programa           
         <dbl> <chr>                     
1         6527 Administración de Empresas
2        11428 Contaduría Pública
  1. comment: permite especificar un carácter (comúnmente #) para que read_csv() ignore por completo todas las líneas que inicien con ese prefijo:
Rows: 2 Columns: 2
── Column specification ────────────────────────────────────
Delimiter: ","
chr (1): nombre_programa
dbl (1): codigo_snies

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.
# A tibble: 2 × 2
  codigo_snies nombre_programa           
         <dbl> <chr>                     
1         6527 Administración de Empresas
2        11428 Contaduría Pública
  1. col_names: controla los nombres de las columnas. Si el archivo no incluye una fila de encabezado, se especifica col_names = FALSE (lo que asigna nombres automáticos X1, X2, etc.) o se proporciona un vector de caracteres con los nombres deseados:
Rows: 2 Columns: 2
── Column specification ────────────────────────────────────
Delimiter: ","
chr (1): programa
dbl (1): snies

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.
# A tibble: 2 × 2
  snies programa                  
  <dbl> <chr>                     
1  6527 Administración de Empresas
2 11428 Contaduría Pública
  1. na: define qué valores de texto deben interpretarse como datos faltantes (NA), por defecto na = c("", "NA"). Si un archivo representa los valores ausentes con expresiones como "Sin dato" o "N/D", pueden indicarse explícitamente mediante na = c("", "NA", "Sin dato", "N/D").

13.2 Otros formatos de archivos de texto plano

Además de los archivos .csv, el paquete readr proporciona funciones dedicadas para importar otros formatos rectangulares de texto plano de uso común:

  • Valores separados por tabulaciones (read_tsv()): se utiliza cuando el delimitador entre columnas es una tabulación (\t):
Rows: 2 Columns: 2
── Column specification ────────────────────────────────────
Delimiter: "\t"
chr (1): nombre_programa
dbl (1): codigo_snies

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.
# A tibble: 2 × 2
  codigo_snies nombre_programa           
         <dbl> <chr>                     
1         6527 Administración de Empresas
2        11428 Contaduría Pública
  • Archivos delimitados por punto y coma (read_csv2()): en países hispanohablantes y europeos donde la coma (,) se utiliza como separador decimal, los archivos CSV suelen utilizar el punto y coma (;) como separador de columnas. La función read_csv2() gestiona automáticamente esta convención:

  • Archivos de ancho fijo (read_fwf()) y tablas alineadas (read_table()): en archivos donde las columnas no utilizan delimitadores sino que ocupan posiciones y longitudes fijas de caracteres, se utiliza read_fwf() junto con asistentes como fwf_widths() o fwf_positions(). Si los campos están separados por uno o más espacios en blanco, read_table() permite realizar la importación directamente.

  • Lectura de texto plano no estructurado (read_lines()): cuando se requiere leer un archivo línea por línea como un vector de caracteres simple sin imponer una estructura tabular, se utiliza la función read_lines().

13.3 Control de tipos de columnas y resolución de problemas

Al importar un archivo de texto plano, readr lee de forma predeterminada las primeras 1000 filas para inferir el tipo de dato más apropiado para cada columna (col_guess()). Para consultar la especificación que readr ha determinado, se utiliza la función spec():

cols(
  codigo_snies = col_double(),
  nombre_programa = col_character()
)

13.3.1 Especificación explícita de tipos con col_types

Cuando las primeras 1000 filas no son representativas o cuando se desea asegurar un esquema de datos reproducible y robusto, es recomendable definir explícitamente los tipos de cada columna mediante el parámetro col_types y la función cols():

  • col_integer(): enteros (<int>).
  • col_double(): números reales (<dbl>).
  • col_character(): texto (<chr>).
  • col_logical(): booleanos (<lgl>).
  • col_factor(): variables categóricas o factores (<fct>).
  • col_date() / col_datetime() / col_time(): fechas y horas.
  • col_skip() (o _ / -): omite la columna durante la importación.

  codigo_snies nombre_programa                              
         <int> <chr>                                        
1         6527 Administración de Empresas                   
2       108241 Administración de Riesgos, Seguridad y Salud…
3        11428 Contaduría Pública                           
4        11004 Ingeniería Civil                             
5        53703 Ingeniería Industrial                        
6       105142 Ingeniería Informática                       
7        10963 Relaciones Internacionales y Estudios Políti…

13.3.2 Diagnóstico de errores con problems()

Si el archivo contiene registros con formatos inesperados (por ejemplo, texto en una columna que fue declarada o inferida como numérica), readr reemplaza el valor conflictivo con NA y emite un mensaje de advertencia. La función problems() permite inspeccionar exactamente en qué fila, columna y valor ocurrió la anomalía:

Warning: One or more parsing issues, call `problems()` on your data
frame for details, e.g.:
  dat <- vroom(...)
  problems(dat)
# A tibble: 1 × 5
    row   col expected   actual     file                    
  <int> <int> <chr>      <chr>      <chr>                   
1     3     1 an integer Sin código /tmp/RtmpqA6U3g/vroom-c…

Para resolver discrepancias relacionadas con formatos de fecha, separadores decimales o codificación de caracteres (por ejemplo, UTF-8 frente a latin1), se puede emplear el parámetro locale = locale(...), definiendo explícitamente aspectos como decimal_mark = "," o formatos de fecha con col_date(format = "%d/%m/%Y").

13.4 Exportación de archivos de texto plano

Para guardar tibbles o marcos de datos de R en archivos de texto plano rectangulares, el paquete readr provee las funciones write_csv(), write_tsv() y write_delim().

Los parámetros más relevantes al exportar datos son:

  • x: el objeto de R (tibble o data frame) que se desea guardar.
  • file: la ruta y nombre del archivo de destino.
  • na: la cadena de texto utilizada para escribir los valores faltantes (por defecto "NA").
  • col_names: valor lógico que indica si se escriben los encabezados de columna en la primera línea (por defecto TRUE).
  • quote: especifica la regla para entrecomillar campos de texto ("needed", "all" o "none").
  • append: valor lógico que indica si las filas deben agregarse al final de un archivo existente (FALSE por defecto).

En comparación con el formato binario .rds (visto en el Capítulo 12), los archivos de texto plano (.csv, .tsv) ofrecen la ventaja de ser universales e interoperables con cualquier herramienta de análisis, lenguaje de programación (como Python o Julia) y gestores de bases de datos. No obstante, dado que no almacenan los metadatos propios de R (como el orden de los factores o las clases personalizadas), al volver a importarlos será necesario especificar nuevamente sus tipos de columna.
